# Prototype vs. Broader Game Concept

This document separates features demonstrated by the playable Unity prototype from ideas developed in the original game-design document.

## Implemented in the Playable Prototype

- University investigation stage.
- Collectible clue system.
- 15-clue progression gate.
- Altar / weapon interaction.
- City combat stage.
- 18-target progression gate.
- Demon Tree mini-boss interaction.
- Castle / hostage-rescue stage.
- 4-hostage progression gate.
- Impostor-hostage interaction.
- Gothic cemetery / final level.
- Dracula / Vampire King interaction.
- Context-sensitive objective UI.
- Location-trigger feedback.
- Sound events.
- Bat spawning effect.
- Scene/menu flow.
- Persistent clue value using PlayerPrefs.

## Broader Concept / Design Direction

The original design document explores additional systems that are part of the intended game direction rather than complete features of the current prototype:

- Day / night gameplay structure.
- Humanity / morality meter.
- Bloodlust and health-management systems.
- Dialogue trees and NPC reputation.
- Safe Zones and Challenge Zones across Lesvos.
- Stealth-based approaches.
- More developed combat and skill progression.
- Dynamic / adaptive audio.
- Branching quests and multiple endings.
- World-state changes based on player choices.

This distinction is intentional: the portfolio presents the implemented build accurately while also showing the larger design thinking behind the project.
